# 思考节流（dsh-thinking-guard）

> 给 DeepSeek Harness 用的一个设置入口：把「工具与技能怎么用」「运行情况怎么样」「重复调用怎么提醒」放在一起看、一起管。

## 它解决什么问题

- 工具和技能太多，不知道哪些开着、哪些按需调用、哪些已禁用。
- 想看看执行保护有没有在工作，却只能翻日志。
- 重复调用、来回空转浪费额度，没有人提醒。
- 统计数字一重启就归零，看不到长期情况。

## 主要功能

**一个入口，三个子页**

| 子页 | 你能做什么 |
|---|---|
| 总览 | 一屏看懂执行保护计数、开关状态、能力目录分布与诊断 |
| 思考限制 | 打开/关闭三类提醒，改阈值；只提醒、不硬停任务 |
| 能力菜单 | 按工具/技能查看与切换「常驻 / 按需 / 禁用」，注册 MCP 服务器与技能目录 |

**执行保护**
- 相同调用重复提醒、交替循环识别、无进展保护，三档互相独立。
- 只在证据明确时局部拦一次，不结束任务。
- 计数会**保存在本机**，重启或更新插件都不会清零。

**隐私**
- 只统计次数与时间，不记录工具名、参数、结果或聊天内容。
- 不读取会话历史。

## 安装

在 DeepSeek Harness 中使用命令行安装（一条命令）：

```powershell
dsh plugin --profile desktop add dsh-thinking-guard
```

安装完成后**重启 DeepSeek Harness**，设置里会出现「思考节流」。

升级到指定版本：

```powershell
dsh plugin --profile desktop remove dsh-thinking-guard
dsh plugin --profile desktop add dsh-thinking-guard@0.3.3
```

## 使用

1. 打开 **设置 → 思考节流**。
2. 顶部三个页签切换：**总览 / 思考限制 / 能力菜单**。
3. 总览看数字；思考限制改开关与阈值；能力菜单点工具或技能的档位标签即可切换。

## 安装前后对比

| 项目 | 安装前 | 安装后 |
|---|---|---|
| 设置入口 | 没有这个功能 | 多一个「思考节流」，三个子页 |
| 工具/技能管理 | 只能看默认列表 | 可切「常驻 / 按需 / 禁用」 |
| 重复调用 | 无提醒 | 按阈值提醒，证据明确时局部拦截 |
| 运行数据 | 无 | 总览页一屏可见 |
| 数据保留 | — | 计数持久化，重启/更新不清零 |

## 常见问题

- **设置里没出现？** 装完要重启 DeepSeek Harness，不是刷新页面。
- **总览数字是 0？** 说明这段时间没有工具调用经过执行保护；用它判断是否生效。
- **从旧版本升级？** 旧版本的档位与开关会自动迁移，不需要手动处理。
- **想回退？** 重新安装旧版本即可，配置会保留。

## 版本
